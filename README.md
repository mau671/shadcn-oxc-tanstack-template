# tamagui-oxc-tanstack-template

Web starter built with:

- `Vite`
- `React 19`
- `TypeScript`
- `TanStack Router` with file-based routing
- `TanStack Query`
- `Tamagui`
- Installed UI packages: `@tamagui/accordion`, `@tamagui/avatar`, `@tamagui/card`, `@tamagui/list-item`
- `oxlint + oxfmt`

## Commands

```bash
pnpm install
pnpm dev
pnpm format
pnpm format:check
pnpm typecheck
pnpm lint
pnpm lint:fix
pnpm check
pnpm build
```

## Route structure

The template uses directory-based routing under `src/routes`:

```text
src/routes/
  __root.tsx
  index.tsx
  about.tsx
  workbench/
    route.tsx
    index.tsx
    tokens.tsx
```

`routeTree.gen.ts` is generated by TanStack Router. The scripts run `tsr generate`
before typechecking or building so the generated file is always present.

## Notes

- `pnpm` is the intended package manager.
- `Tamagui` is configured through `tamagui.build.ts` and `tamagui.config.ts`.
- The page UI uses installed `@tamagui/*` component packages instead of local hand-rolled UI components.
- `oxlint` and `oxfmt` are configured directly through `.oxlintrc.json` and
  `.oxfmtrc.jsonc`.
- `oxlint` is fast, but real type checking still comes from `tsc -b`.
