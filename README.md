# shadcn-oxc-tanstack-template

Web starter built with:

- `Vite`
- `React 19`
- `TypeScript`
- `TanStack Router` with file-based routing
- `TanStack Query`
- `shadcn/ui` (CLI-managed components)
- `oxlint + oxfmt`

## Commands

```bash
pnpm install
pnpm dev
pnpm format
pnpm format:check
pnpm typecheck
pnpm lint
pnpm lint:fix
pnpm check
pnpm build
```

## Route structure

The template uses directory-based routing under `src/routes`:

```text
src/routes/
  __root.tsx
  index.tsx
  about.tsx
  workbench/
    route.tsx
    index.tsx
    tokens.tsx
```

`routeTree.gen.ts` is generated by TanStack Router. Scripts run `tsr generate`
before typecheck/build so the generated file stays in sync.

## Notes

- `pnpm` is the intended package manager.
- shadcn components are managed via CLI (`pnpm dlx shadcn@latest add ...`).
- `oxlint` and `oxfmt` are configured directly through `.oxlintrc.json` and `.oxfmtrc.jsonc`.
- `tsc -b` remains the source of truth for type errors.
